💡 Helpful Information

🎯 Where to Start?
1. Calendar Dashboard: Your main view. Navigate the month, see what's missing.
2. Daily Notifications: Keep open to receive alerts at 9am and 5:45pm.
3. Metrics Dashboard: End of week, review what happened vs goals.
4. Journal System: For deep reflection (Friday + Sunday especially).
5. Playbook: Add new objections to improve your scripts.
📊 KPIs to Track
Daily: Calls, responses (ratio), talks, proposals, average time
Weekly: Total calls (goal 50), talks (goal 4), talk→proposal conversion
Monthly: Total calls (goal 200), talks (goal 16), revenue, trend
💾 Storage
Everything saves to browser localStorage (no server). Data persists between sessions. Doesn't require internet (once loaded). If you need to switch browsers, you can export from localStorage.
🔄 Pipedrive Integration
This system is your personal "business intelligence". Pipedrive remains your primary CRM. You can record contacted clients in Daily Task Manager and then transfer to Pipedrive, or vice versa.
✅ Cowork Setup
1. Create new workflow
2. Add task "Open Daily Notifications" (9:00am)
3. Add task "Register metrics" (variable)
4. Add task "Friday Journal" (Friday)
5. Add task "Sunday Journal" (Sunday)
6. Save links to each tool in notes
